# Datasets

## CIFAR-10

The CNN notebook uses `torchvision.datasets.CIFAR10` with automatic downloading enabled. Run the notebook to download CIFAR-10 into `data/cnn/`; no manual download is needed.

## IMDB Dataset.csv

Download **IMDB Dataset.csv** (the dataset of 50K movie reviews) from [Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews). Place it in `data/rnn/`.

The RNN notebook reads `data/rnn/IMDB Dataset.csv`. Dataset files are excluded from version control.
